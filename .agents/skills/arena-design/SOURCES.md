# Source curation report

Audited on 2026-09-11. The skill instructions in this pack are independently authored. Repository links are references and possible future integrations, not copied source code.

| Skill | Curated source | Repository status / license note |
|---|---|---|
| `excalidraw` | <https://github.com/excalidraw/excalidraw> | Active; MIT. Full whiteboard application, so this pack generates compatible artifacts rather than installing the app. |
| `penpot` | <https://github.com/penpot/penpot> | Active; MPL-2.0. Large multi-service design platform; optional remote/dev integration only. |
| `onlook` | <https://github.com/onlook-dev/onlook> | Active; Apache-2.0. Full visual React editor, not a small skill package. |
| `shadcn-ui-engine` | <https://github.com/shadcn-ui/ui> | Active; MIT. Upstream describes components/code distribution; this wrapper does not install its CLI. |
| `assistant-generative-ui` | <https://github.com/assistant-ui/assistant-ui> | Active; MIT. React/TypeScript library; dependency use remains opt-in. |
| `design-md-tokens` | <https://github.com/VoltAgent/awesome-design-md> | Active; MIT. The supplied `kaushikgopal/awesome-design-md` URL returned GitHub API 404 and was corrected during curation. Extracted brand styles are inspiration, not permission to clone trade dress. |
| `ui-ux-pro-max` | <https://github.com/heroui-inc/heroui> | Active; Apache-2.0. The supplied NextUI URL redirects to HeroUI. There is no official upstream package named `ui-ux-pro-max`. |

| `visual-regression-qa` | <https://github.com/puppeteer/puppeteer> | Active; Apache-2.0. Puppeteer is browser automation, not a complete pixel-diff policy. The wrapper prefers existing browser tooling. |
| `remotion-best-practices` | <https://github.com/remotion-dev/remotion> | Active; custom Remotion License. Current terms allow specified individuals/small organizations and require a company license for some for-profit organizations; eligibility must be confirmed before installing. |
| `understand-figma` | <https://github.com/figma/plugin-samples> | Active; MIT. Samples are examples, not a ready-made Figma-to-knowledge-graph parser. |

## Installation posture

- Upstream code installed: **no**.
- Production dependencies changed: **no**.
- Services started: **no**.
- Credentials requested or stored: **no**.
- Heavy tools: opt-in, development-only or remote-first.
