# Triage labels

The engineering skills use these canonical roles. This repository maps them to
the same GitHub label names:

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer still needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires a human action or decision |
| `wontfix` | `wontfix` | Deliberately not being actioned |

When a skill names a canonical role, use the corresponding GitHub label above.
