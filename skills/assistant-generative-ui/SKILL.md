# Assistant Generative UI — AI Interface Primitives (assistant-ui Protocol)

## Purpose
Provides rich, interactive UI components designed specifically for AI agent interactions, including streaming text cards, tool execution summaries, and inline visualization canvas widgets.

## Guidelines
- Render tool execution states cleanly with loading spinners, expandable diffs, and result cards.
- Separate streaming content from persistent state artifacts.
- Provide interactive controls for human-in-the-loop decisions.
