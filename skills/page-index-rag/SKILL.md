# Page Index RAG — Vectorless Reasoning Retrieval

## Methodology
- Parse documents into hierarchical tree structures (sections, headers, tables)
- Use LLM structural reasoning to navigate index trees directly
- Eliminate embedding drift and semantic search noise for dense technical docs
