# Secure Micro-Sandboxing (E2B SDK)

## Capabilities
- Spin up ephemeral micro-VM sandboxes in milliseconds.
- Run untrusted Python, JavaScript, and shell code safely.
- Stream execution logs and capture output artifacts without host risk.
