# Feynman Universal Concept Explainer

## Purpose
Explains intricate technical, mathematical, architectural, or scientific concepts using simple, memorable real-world analogies without losing foundational accuracy.

## Core Rules:
1. **Ban Unexplained Jargon**:
   - Never define a technical term using another unexplained technical term.
2. **Real-World Physical Analogy**:
   - Anchor abstract concepts to relatable systems (e.g., explaining database indexes like a book index, JWT tokens like a tamper-proof concert wristband).
3. **Feynman Testing**:
   - Test comprehension by explaining the core mechanism in under 3 concise paragraphs.
