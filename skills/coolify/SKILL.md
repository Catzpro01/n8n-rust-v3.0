# Coolify — Self-Hosted PaaS Management

## Capabilities
- Deploy apps, databases, and services via Git push or Docker Compose
- SSL certificate management (Let's Encrypt)
- Resource monitoring and environment variable management

## Security
- Restrict dashboard access via strong MFA
- Do not expose internal database ports directly to the internet
