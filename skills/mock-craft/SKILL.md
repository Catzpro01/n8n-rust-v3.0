# Mock Craft — Synthetic API & Fixture Generator

## Purpose
Generates local, zero-dependency mock API endpoints and realistic synthetic fixture datasets from TypeScript types, OpenAPI schemas, or database models.

## Capabilities
- Parse TypeScript interfaces, Zod schemas, and Prisma models into realistic mock JSON data.
- Emulate HTTP status codes, latency delays, and pagination contracts.
- Provide self-contained mock fixtures for isolated frontend and unit test development.
