# Code-Driven Control Flow (Code-as-Workflow)

## Philosophy
Replace ambiguous prompt instructions with deterministic Python/TypeScript logic:
- Conditionals (`if/else`), iterations (`for/while`), and retries (`try/except`) execute in code, not prompt text.
- LLMs are invoked strictly as pure functions for unstructured transformations.
