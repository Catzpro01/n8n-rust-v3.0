# Decentralized Trust-Bound Agent Swarms

## Protocol
- Cryptographic identity verification (public/private key signing per agent).
- Bounded execution capabilities bounded by smart contracts / signed tokens.
- Secure enclave isolation for cross-organizational swarms.
